# images/

Assets referenced by the decks and by `\abishalogo`.

- `logo_ipb.png` — title-page logo used by `main.tex` and the example deck.
  Swap it for your own, or pass a different path to `\abishalogo`.
- The example deck in `../examples/` also expects `mnist_7.png`,
  `gambar_input.jpg` and `celeb (1..7).jpg`. Those photographs are not part of
  this repository; without them the deck draws correctly sized placeholders.
